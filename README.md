# fuelapp
Веб приложение для ведения учета заправок автомобиля.
Для установки создайте дерикторию, например:
cd /opt && mkdir fuelapp_install && cd fuelapp_install
По SFTP поместите в нее fuelapp.sh
Сделайте его исполняемым chmod +x fuelapp.sh и запустите ./fuelapp.sh
При запуске скрипта появиться меню:
============================================================
                 FUEL CONTROL
             Управление приложением
============================================================

  1. Установить / обновить
  2. Показать статус
  3. Перезапустить
  4. Удалить
  5. Выход

Выберите действие [1-5]:

Нажмите установить программа запросит порт:
------------------------------------------------------------
 Установка / обновление Fuel Control
------------------------------------------------------------
Порт веб-интерфейса [5000]:

Выберете свободный порт на вашем ПК.
Далее установщик сделает системные зависимости и Python окружение.
